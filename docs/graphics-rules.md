# 그래픽 자산 규칙

Sprite 또는 Effect의 palette를 생성·변경할 때는 [GBA Sprite Palette Harness](harness/gba-sprite-palette.md)를 함께 따른다.

## 빌드 연동

- Butano는 루트 `Makefile`의 `GRAPHICS`에 등록된 자산 디렉터리를 처리한다.
- 새 자산 디렉터리가 기존 등록 범위에 포함되지 않으면 `GRAPHICS`에 추가한다.
- Butano 스프라이트의 JSON 메타데이터는 해당 이미지와 같은 디렉터리에 둔다.
- 메타데이터의 프레임 크기는 코드에서 사용하는 프레임 배열과 일치해야 한다.

## 방향 순서

방향별 캐릭터 시트와 코드는 다음 순서를 사용한다.

1. `DOWN`
2. `DOWN_LEFT`
3. `LEFT`
4. `UP_LEFT`
5. `UP`
6. `UP_RIGHT`
7. `RIGHT`
8. `DOWN_RIGHT`

이 순서는 `include/game/direction.h`에 정의되어 있으며 캐릭터 스프라이트 타일 인덱스로 직접 사용된다. 방향 enum, 방향별 프레임과 조회 테이블을 서로 다르게 재정렬하지 않는다.

현재 거너와 검사 방향 시트는 높이 16픽셀의 캐릭터 프레임을 사용하며 JSON 메타데이터에 `"height": 16`이 지정되어 있다. 모든 캐릭터나 이펙트가 같은 크기를 사용한다고 가정하지 말고, 인접한 JSON과 소비 코드를 확인한다.

## 검사 참격 이펙트

현재 검사 참격 생성 도구는 다음 규격을 정의한다.

- 8방향 시트
- 방향마다 5프레임
- 프레임 크기 64×64픽셀
- 시트 크기 320×64픽셀
- indexed 8bpp 팔레트 BMP
- 고정 팔레트
- 오른쪽 계열은 왼쪽 계열을 정확히 좌우 반전하여 생성
- `Direction`과 같은 방향 순서

검사 참격 자산은 `tools/generate_swordsman_slash_effects.py`를 기준으로 삼는다. 생성 결과만 따로 수동 편집하지 않는다.

Python과 Pillow를 사용할 수 있으면 프로젝트 루트에서 다음 명령을 실행한다.

```bash
python tools/generate_swordsman_slash_effects.py
```

이 도구는 BMP 비트 깊이, 팔레트 모드, 크기, 프레임 수, 팔레트 인덱스, 방향별 허용 영역, 좌우 반전과 승인된 프레임 해시를 검증한다.

indexed 8bpp 규칙은 현재 생성되는 검사 참격 BMP에서 확인된 규격이다. 각 자산의 실제 형식과 Butano 메타데이터를 확인하지 않고 모든 프로젝트 그래픽에 일반화하지 않는다.

## 기존 자산 변경

변경 전에 다음을 확인한다.

- 이미지 형식과 비트 깊이
- 팔레트와 투명색
- 시트 및 프레임 크기
- 프레임 수와 방향 순서
- 인접한 JSON 메타데이터
- 생성 도구 또는 원본 자산
- 생성된 Butano 항목을 참조하는 코드

요청이 명시적으로 요구하지 않는 한 기존 크기, 프레임 순서, 팔레트, 대칭 관계와 메타데이터를 보존한다.

## 검증

빌드 대상 그래픽을 변경하면 다음을 확인한다.

1. 관련 생성 또는 검증 도구를 실행한다.
2. 의도한 생성 파일만 변경되었는지 확인한다.
3. Butano 도구 체인이 있으면 `make clean` 후 `make -j2`를 실행한다.
4. mGBA에서 방향, 위치, 프레임 순서, 투명색과 팔레트를 확인한다.
5. 에뮬레이터 확인 결과를 빌드 성공과 구분해 보고한다.
