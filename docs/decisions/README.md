# 설계 결정 기록

이 디렉터리는 프로젝트의 중요한 설계 결정과 그 이유를 보존한다.

## 원칙

- 코드가 현재 동작의 1차 근거다.
- 결정 기록은 당시의 설계 의도와 이유를 보존하는 2차 근거다.
- 기존 결정을 나중에 바꾸더라도 과거 기록을 현재 결론으로 덮어쓰지 않는다.
- 기존 결정을 대체하는 경우 새 결정 기록에서 어떤 결정을 대체하는지와 변경 이유를 남긴다.
- 구현 편의를 이유로 중요한 결정을 AI가 임의 변경하지 않는다. 충돌이 발견되면 사용자에게 보고하고 승인 후 반영한다.

## 기록 대상

모든 작업을 기록하지 않는다. 다음과 같이 나중에 다시 물어볼 가치가 있는 판단만 남긴다.

- 시스템 책임 분리
- 여러 대안 중 하나를 선택한 이유
- 성능·메모리·GBA 제약 때문에 선택한 구조
- 기존 결정을 뒤집은 이유
- 이후 구현에 반복적으로 영향을 주는 원칙

작업 내역 자체는 Git commit, Issue, PR을 우선 사용한다.
